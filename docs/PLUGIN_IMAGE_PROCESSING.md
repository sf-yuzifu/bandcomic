# 同步器共用图片成品处理（P1-45）

## 适用范围

AstroBox 同步器的本地漫画导入使用同一个 `src/image_processor.rs` 生成图片成品，HTTP 下载及旧互联单本、多章、单章发送共用参数、缩放、透明处理、格式和缓存规则。最低上传快应用版本仍为 382，沿用现有图片参数及 `import_comic_*` 协议。

```text
选图 → 有界解码 → 素材缩略图 + PNG 母版 → cache/masters
                                            ↓
设备设置 / HTTP 参数 → 归一化 → 共用成品处理器 → cache/rendered
                                            ├─ HTTP 原始图片 body
                                            ├─ 旧互联 Base64 分片
                                            └─ 后续成品预览 / 估算
```

## 输出规则

| 用途 | 宽度 | 格式优先级 | 透明区域 | 设备文件 |
| --- | --- | --- | --- | --- |
| 正文 | 设置值限制为 10..4096，小图不放大 | LVGL I8 > PNG > JPEG | PNG 保留 alpha；JPEG/LVGL 合成白底 | 普通图片 `1`；LVGL `1.bin` |
| 封面 | 上限固定 80，小图不放大 | PNG > JPEG；忽略 LVGL | 同对应格式的正文规则 | `cover` |

- 统一使用 Triangle 缩放；综合宽度、格式尺寸和像素预算计算最终尺寸后执行一次成品缩放。
- `quality` 只影响 JPEG，先限制为 1..100 再转换为编码器参数。PNG 为无损编码，LVGL 使用固定 256 色 I8 调色板。
- MIME 从成品格式派生：JPEG 为 `image/jpeg`，PNG 为 `image/png`，LVGL 为 `application/octet-stream`。HTTP 的 `.jpg` 路由仍可按参数返回其他格式。
- 选图先生成宽度上限 1280 的 PNG 母版和 100×200 边界内的素材缩略图。当前编辑界面展示素材缩略图；设备成品按握手获得的设置生成。

## 首版预算与长图

| 项目 | 上限 |
| --- | --- |
| 输入文件 / 母版读取 | 32 MiB |
| 输入宽高 | 各 65535 |
| 输入像素数 | 32×1024×1024 |
| 解码器分配预算 | 128 MiB |
| 单张成品像素数 | 4×1024×1024 |
| 单张成品编码体积 | 16 MiB |
| LVGL 宽高 | 各 1..2047 |

解码前检查输入尺寸和像素预算，解码器同时使用 `image::Limits`；编码写入器限制输出体积。总峰值还包括缩放、量化、成品和互联传输缓冲，准备耗时、峰值及真机阅读效果按验收记录测量。

LVGL 编码器在自己的入口再次检查尺寸，合法 I8 成品长度为 `1028 + width × height`。长图按比例缩小到合法尺寸，插件概览保留实际宽高和缩小说明。例如 600×6000 的 LVGL 正文约为 205×2047，文字宽度随之缩小。保留目标文字宽度的长图切页及切点编辑见 P3-23。

## 缓存与错误

- 成品键包含处理器版本、母版内容 hash、用途、归一化宽度、实际格式及生效的质量参数。PNG/LVGL 的质量不影响编码，也不形成不同成品键。
- `cache/rendered/*.img` 为单文件缓存封装：魔数、JSON 元数据和真实编码字节一起原子提交。元数据包含参数、源/成品宽高、字节长度及内容 hash；命中时核对版本、身份、参数、完整性、实际格式和尺寸。
- 损坏或过期成品重新生成；缓存读写失败有日志，成功生成的有效内存成品仍可返回。缓存命中保持相同字节、格式、宽高和尺寸说明。
- 母版也采用临时文件原子提交；重新选择同一有效图片会核对并修复缺失/损坏的母版副本。
- HTTP 预算错误返回 413，输入/解码错误返回 422，读取/编码错误返回 500，正文为 JSON 错误。设备下载器继续使用现有 HTTP 状态及文件头校验。
- 旧互联在 header 发送前准备成品；母版读取、解码、编码或预算失败显示文件名及章节/页码、阶段，停止本次准备。文件名根据成功生成的成品格式决定。
- HTTP 的处理说明和失败原因只补充到仍在处理同一本作品的活动任务；其他作品的访问不修改本次上传说明。概览说明最多保存 8 条。

## 成品预览接口

`prepare_image()` 返回成品字节、实际格式、宽高和尺寸说明。`product_preview()` 从这些最终字节生成 PNG 展示图：JPEG 包含实际压缩损失，LVGL 按最终调色板/索引还原颜色，PNG 保留 alpha。可视化预览、整本体积估算和切页交互接在 P3-23。

处理算法、透明策略或预算规则发生变化时升级 `RENDER_VERSION`，使旧成品缓存失效。

## 自动化与真机验收

Native 测试覆盖格式优先级、透明/半透明、封面、小图、LVGL 边界/长图、输入/编码/磁盘预算、缓存完整性与版本、JPEG 质量变化、真实成品预览及母版修复。

实际 release WASM 通过真实 UI 选图、握手和 HTTP handler，重组停等/滑窗发送的 Base64 分片，与独立冷渲染的 HTTP body 逐字节比较；覆盖单本四种开关组合、多章、单章、缓存命中/损坏和坏图/缺失/损坏母版。运行：

```text
cargo test --locked --target x86_64-pc-windows-msvc
python scripts/build_dist.py --release --package --locked
cargo run --locked --manifest-path scripts/v4_runtime_check/Cargo.toml --target x86_64-pc-windows-msvc --target-dir target/v4-runtime-check -- dist/bandcomic_astrobox_v2_plugin.wasm
```

调试图片子矩阵可在最后一条命令末尾追加 `--images-only`。真机验收见 `todo.md` 的 V-100～V-106，分别记录 9 Pro HTTP、10 Pro 互联及兼容客户端的设备文件和阅读结果。
